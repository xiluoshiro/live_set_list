# 数据回填 SQL

本目录统一存放所有需要手工执行的数据回填和数据纠正 SQL，不限业务模块。脚本不由应用、Flyway 或自动发布流程执行。

## 文件约定

- 使用 `YYYY-MM-DD-NN__description.sql` 命名，编号表示同日执行顺序。
- 每个脚本说明用途、目标范围、前置条件、执行顺序依赖和重复执行策略。
- 提供纯 SQL，直接执行的脚本使用事务并在成功后 COMMIT，不依赖 psql 元命令或隐含提交开关。
- 具体业务背景、数据约束和使用说明放在对应文档中，不在本 README 维护任务清单。

## 验证范围

独立回填 SQL 的变更只做格式检查及相关测试库验证，不触发完整 `functional`。纯搬迁、重命名和引用调整只核对内容、哈希与路径；同时修改应用、API、schema 或 seed 时，遵守项目相应检查规则。

维护规则见 [AGENTS.md](AGENTS.md)，经验教训见 [LESSONS.md](LESSONS.md)。
