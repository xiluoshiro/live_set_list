# 公共端视觉规范

## 布局

- 宽窄屏均应保持标题、日期和操作可读，长日期范围及标题可以合理换行，不能互相覆盖。
- 手机导航使用移动端抽屉；数据概览使用紧凑网格，避免单列大卡片占满首屏。
- 列表筛选、视图切换和分页采用一致的控件结构，明确显示当前选择及禁用状态。
- 详情返回使用明确的返回语义，元数据按屏幕宽度自然重排。

## 样式与状态

- 使用现有主题、颜色、形状和层级令牌，避免重复定义控件及硬编码悬停色。
- 正文和背景保持对比度；主题色用于重点和交互状态，不铺满整个页面。
- 加载、空数据、错误、焦点、悬停及禁用状态均可区分。
- 动效遵循 `prefers-reduced-motion`，不能阻碍内容读取和操作。
- 乐队 SVG 属于数据视觉资产，不因公共控件图标调整而改写。

## 可访问性

- 卡片主入口使用可键盘操作的元素，详情、收藏和来源链接分别提供独立操作目标。
- 图标按钮及来源外链具有完整可访问名称；焦点清晰可见。
- 不在按钮内嵌套按钮，选择状态通过适当的 ARIA 属性暴露。

## 视觉检查

在宽屏、手机及深浅色主题下检查首页、列表两种视图、详情和乐队浏览。行为测试不能代替真实浏览器对裁切、溢出、对齐及底部可达性的检查。相关边界见[全局样式覆盖缺口](../../fails/frontend-global-style-coverage-gap.md)。
