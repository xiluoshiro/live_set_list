# 活动出演成员需求（已完成）

## 文档定位

状态：已完成并归档。当前接口字段与行为以代码、OpenAPI 和 [API 补充说明](../../api.md) 为准。

本文定义 `live_type=event` 时记录和展示出演成员的产品需求，不规定数据库字段、接口 JSON 或组件实现。实现方式见 [活动出演成员实现设计](../completed-design/event-attendees.md)。

## 背景

活动类型的 Live 通常没有 Setlist，只通过默认 Band 在演出资料列表中展示乐队缩略图。但活动可能只有某支乐队的部分成员出席，详情需要在保留乐队身份的同时说明具体成员。

## 产品规则

- 只有 `live_type=event` 可以记录和展示出演成员。
- 演出资料列表保持现状，只展示默认 Band 缩略图，不展示成员。
- 详情继续展示 `乐队：MyGO!!!!! / Ave Mujica`。
- 有出演成员数据时，在下一行展示紧凑的 `出演成员：`。
- 部分成员逐人展示，每个人名前显示所属 Band SVG。
- 全员出席时显示一次 Band SVG 和“全员”，但后台仍保存完整成员名单。
- 没有出演成员数据时不显示这一行，不显示“未记录”等占位文案。
- 非活动类型不得因为残留数据显示出演成员。

## 目标展示

```text
乐队：MyGO!!!!! / Ave Mujica / 梦限大みゅーたいぷ
出演成员：[MyGO SVG] member1 / [MyGO SVG] member2 / [Ave Mujica SVG] member3 / [梦限大 SVG] 全员
```

## 验收标准

1. 无 Setlist 的活动详情能从默认 Band 正确显示乐队，不再显示为空。
2. 部分成员按成员逐项显示 Band SVG 和姓名。
3. 全员只显示一个“Band SVG + 全员”，数据中仍保留完整成员数组。
4. 列表、乐队筛选、Setlist 和统计口径不因该字段发生变化。
5. 非活动详情不显示出演成员。
