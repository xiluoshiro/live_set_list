# 歌曲归属与乐队关联

## 数据职责

| 对象 | 职责 |
| --- | --- |
| 歌曲组 | 歌曲共同身份、标题、版本顺序及历史演奏统计；不保存独立归属 |
| 歌曲版本 | 名称、版本标识、封面及正式归属 |
| 专辑 | 发行资料、封面和有序收录关系；收录行关联具体歌曲版本 |
| 演出歌单 | 引用歌曲组，保存实际出演乐队、阵容及成员事实 |

歌曲版本归属使用 `song_list.owner_mode`、`song_bands`、`song_member_groups` 和 `song_members`：

- `bands`：至少一个整队关系，没有成员分组。
- `members`：至少一个非空成员分组，没有整队关系。
- `mixed`：整队关系和成员分组同时存在。
- `pending`：数据库 `owner_mode` 为空，两类关系均为空。

候选、管理详情、公开搜索和专辑曲目统一读取正式关系。尚未核实的归属显示“待回填”，不从出演乐队或旧单值补出正式归属。

## 创建与编辑

- 单曲新增、歌单批量新增及歌单内嵌编辑使用相同归属协议；批量新增逐首确认归属。
- 规范化标题与归属集合用于默认版本去重；归属的展示顺序不影响身份判定。
- 单曲和批量创建共享标题事务锁，批次按稳定顺序加锁。
- 批量结果逐项返回 `index`、完整版本、`created` 或 `error`；失败项回滚，前端保留待修正草稿。
- 歌单从返回版本取得 `group_id`，按结果的 `index` 对应原草稿。
- 编辑加载完整详情及 revision；保存成功后刷新候选、详情和资料缓存。切换对象经过未保存草稿保护。

## 现场翻唱与统计

现场翻唱以歌曲组的默认版本为基准，实际出演另行保存。已知出演乐队与默认版本的整队归属或成员分组所属乐队相交时判为原属；双方事实完整且不相交时判为翻唱；归属或出演资料不足时判为未知。

该计算比较乐队集合，不按固定成员 ID 逐人匹配，也不使用历史 `is_cover` 代替现场事实。同组版本共享按有效歌单记录计算的次数；专辑重复收录不增加演奏次数。

## 旧提示与有效 band_id

`song_list.band_id` 不再存在。旧值仅作为 `song_legacy_band_archived` 审计中的历史线索，不能覆盖正式归属；旧翻唱记录里的乐队可能是出演方，不能未经核实自动回填。

以下关系中的 `band_id` 仍是有效业务键：

- 歌曲整队归属及成员分组上下文。
- 乐队名称、历史阵容、活动与逐曲实际出演。
- 巡演出演、乐队目录、统计维度和筛选参数。

手工回填只消费已审核输入，明确适用结构与目标范围；保留歌曲身份、历史演奏事实和非目标资料。生成及执行规则见[回填说明](../../backfill/song-catalog-2026-09-26/README.md)。
