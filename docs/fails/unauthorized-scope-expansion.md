# 未经确认扩大重构范围

## 问题

时区重构的授权范围是收敛存储、计算、录入校验及已经明确的访问者日期规则。实现时却删除了演出详情的时区缩写显示，将原有 `JST` 等标签统一改成 `UTC+09:00` 等偏移格式。该显示格式变更没有得到授权。

## 原因

- 将“固定偏移不能唯一确定地区时区”的技术判断，直接推导成“页面必须统一显示 UTC 偏移”的产品决定。
- 混淆计算依据与展示格式，未区分必要的内部重构和独立的用户可见行为变更。
- 把重构中发现的问题视为扩大修改范围的许可，未先说明问题及可选方案。

## 工作约束

- 内部存储或计算重构不自动授权修改显示格式、文案、布局、默认值或既有交互；已明确要求的行为变化照常实施。
- 对授权目标所必需的内部实现自主推进；对独立的产品行为变化，先说明与目标的关系、影响和方案，存在未确定需求时使用问题工具澄清。
- 查询实现原理、质疑已有行为或要求审查时，先提供证据和结论，不将询问本身当作修改授权。
- 发现旧实现有缺陷时，区分“修正计算依据”和“改变显示约定”，不能用前者为后者代作决定。
- 检查改动时逐项核对用户可见差异与授权范围；测试通过不能替代需求授权。
- 复盘记录事实、原因和约束，不向设计或实现文档追加对话归因、命令输出、测试结果或执行流水账。
