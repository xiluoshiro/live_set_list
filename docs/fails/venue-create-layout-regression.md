# 新增场地表单结构与文字截断回归

2026-09-19，新增场地两次未正确遵循新增演出的录入结构：先使用两栏堆叠表单并混入历史查询，后又将地区选择塞入主表格，且类型列只有 112px，扣除单元格内边距和选择器箭头后不足以显示完整“实体场馆”。

原因：只复用零散样式，没有以新增演出的查询行、选择行、主表格三个层级逐项核对；自动测试通过不代表控件文字能够完整显示。

修复约束：查询地区与选择地区分别一行，主表格仅放名称、类型、地址、纬度、经度、精确时区；类型列 152px、时区列 220px；类型只有实体场馆和未公开；实体场馆时区必填且沿用坐标约束。新增演出的快捷创建入口转到完整表单，防止绕过校验。

回归检查：自动测试验证两行归属、六列单行、类型顺序、无 online、必填时区和失败提示无重试按钮；浏览器必须检查桌面及窄屏、浅色及深色的完整类型文字、列宽和横向滚动，不能以 jsdom 代替视觉验收。
