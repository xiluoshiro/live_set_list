# 新增场地表单补齐

## 对照与范围

新增演出提供场地查询、默认乐队、日期/标题/类型/链接/开场/开演/时区七项基础资料、演出状态、排期公布状态，以及确认、清空、连续录入。新增场地原来仅有名称和类型。

场地沿用候选查询、分组录入、提交预览、清空和成功后清空选项；增加已公布地区（搜索分页并保留选中项）、地址、WGS84 坐标、IANA 时区，复用所在地管理的地图选点与自动解析。演出日期、阵容、取消状态和排期字段属于 Live，不加入场地。

## 保存与类型约束

创建请求可携带位置资料，名称、首个名称版本和位置在同一数据库事务中写入；复用位置字段校验，检查地区存在及地区/场馆时区一致。线上不保存位置，未公开只允许地区；类型切换清理不适用的草稿。历史名称继续由管理页维护，不能把相似场馆或不同 Hall 自动合并。

地图平台链接需要已存在的场地，创建成功后可在当前页展开现有位置管理组件继续维护。创建请求失败保留输入；创建成功但候选刷新失败明确报告已创建，避免重复提交。

## 验收

覆盖原子写入、非法坐标/类型/时区、分页选项保留、确认内容、失败保留、连续录入与地图衔接。前后端同时修改，最终运行 functional；浏览器检查记录与自动测试分开报告。不修改本地主库资料或既有迁移。
